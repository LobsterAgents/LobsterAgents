## How to Use

Each agent file contains:
1. **Identity** — name, role, department, tier
2. **Model config** — primary model + fallback chain
3. **Personality** — how they communicate
4. **Expertise** — what they're good at
5. **Permissions** — what tools they can access
6. **Responsibilities** — what they do
7. **System prompt** — ready to use for spawning
