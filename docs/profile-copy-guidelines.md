# Lobster Agents — Agent Profile Copy Guidelines

Audience: prospects evaluating whether to hire Lobster Agents.
Goal: make each agent feel credible, specific, and easy to say “yes” to.

---

## 1) Brand voice (what it should feel like)

**High-trust, plainspoken, and practical.**
- Sounds like an experienced operator explaining how they work.
- Confident without swagger; specific without oversharing.
- Written for scanning: short paragraphs, tight bullets, clear labels.

**Positioning:** “Senior help that ships.”
- Focus on outcomes, process, and decision-quality.
- Make it clear *who it’s for*, *what you’ll get*, and *how we’ll run the work*.

---

## 2) Tone and style rules

### Default tone
- **Direct:** fewer adjectives, more nouns/verbs.
- **Warm:** human, not stiff.
- **Evidence-based:** claims backed by examples, metrics, artifacts, or constraints.
- **Low-drama:** no hype, no FOMO.

### Writing style
- Use **first person** (“I”) for the agent voice.
- Prefer **active voice**.
- Prefer **short sentences**.
- Prefer **concrete nouns** (“product roadmap,” “SQL model,” “runbook,” “ad set”) over abstractions (“synergy,” “solutions”).
- Avoid buzzwords; if a term is unavoidable, define it once.

### Consistency
- Use the same section headings across profiles.
- Keep formatting consistent (bullets, colons, bold labels).
- If you mention tools, align to the “Tools I use” section.

---

## 3) What to emphasize (content priorities)

1. **Outcomes** (what changes after working together)
2. **Scope clarity** (what’s included / not included)
3. **How the work runs** (cadence, communication, artifacts)
4. **Decision quality** (how tradeoffs are handled)
5. **Speed + reliability** (how you ship without chaos)

Use these anchors:
- **Who I’m best for**
- **What I deliver** (artifacts)
- **What success looks like** (metrics, milestones)

---

## 4) Do / Don’t

### Do
- **Lead with specificity:** “I build GA4 + BigQuery event pipelines” beats “data-driven growth.”
- **Name your artifacts:** PRDs, dashboards, SOPs, governance docs, wireframes, playbooks.
- **Use ranges and caveats:** “Typically 2–6 weeks depending on data cleanliness.”
- **Make tradeoffs explicit:** speed vs. rigor, manual vs. automated, short-term vs. durable.
- **Show how you collaborate:** with founders, product, design, engineering, ops.
- **Add proof lightly:** 1–2 mini case bullets (what you did + result + context).

### Don’t
- **No inflated claims:** “world-class,” “guaranteed,” “10x,” “revolutionary.”
- **No vague promises:** “optimize,” “leverage,” “unlock,” “transform” without specifics.
- **No insider jargon:** avoid acronyms unless common (e.g., SEO, CAC, LTV) and relevant.
- **No long autobiographies:** prospects care about fit and execution.
- **No fluff lists:** only list tools you can actually use day-to-day.

---

## 5) Length targets (per profile)

Aim for a profile that reads in **2–3 minutes**.

**Hero**
- Name + role title: 3–7 words
- One-liner: 12–20 words
- Credibility bullets: 2–4 bullets, 6–12 words each

**1-paragraph bio**
- 70–120 words

**What I do / How I work / Tools / Typical engagements / Working with me**
- 3–6 bullets per section
- Keep bullets to 1–2 lines

**FAQ**
- 4–7 questions
- 1–3 sentences per answer

**CTA**
- 1 short paragraph + 2–4 bullets

---

## 6) Claim hygiene (how to write credible claims)

Use this structure:
- **What:** the capability
- **Context:** what environment or constraints
- **Evidence:** example, metric, artifact, or decision

Examples:
- “I set up lifecycle email programs (Klaviyo) with clear measurement (holdouts + cohorts).”
- “I ship analytics foundations: event taxonomy → tracking plan → QA → dashboards.”

If you can’t add context/evidence, soften:
- “I’m comfortable with…”
- “I’ve supported teams doing…”

---

## 7) Skimmability checklist

Before publishing, check:
- Headings are consistent and scannable.
- Each section has <= 6 bullets.
- No paragraph longer than 4 lines.
- First 15 seconds answers: **who it’s for + what you deliver + how engagement starts**.

---

## 8) Optional credibility elements (use selectively)

- **Industries:** list only if relevant (e.g., B2B SaaS, eCommerce, fintech).
- **Stage fit:** pre-seed, seed, Series A, growth.
- **Operating mode:** hands-on builder, player/coach, advisory.
- **Availability:** part-time/full-time, time zone overlap.

---

## 9) Common “good” phrases (approved language)

- “I’m best used when…”
- “Typical deliverables include…”
- “We’ll start with a short diagnostic…”
- “I prefer weekly cadence with written updates…”
- “If you already have X, I’ll plug in; if not, I can set it up.”

---

## 10) Final QA (copy/paste)

- [ ] Does the one-liner clearly state **role + outcome + audience**?
- [ ] Are deliverables tangible (docs, dashboards, code, processes)?
- [ ] Are timelines and scope boundaries present?
- [ ] Does the profile avoid hype and vague claims?
- [ ] Would a skeptical operator believe it?
