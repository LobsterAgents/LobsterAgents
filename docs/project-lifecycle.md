# Project Lifecycle

This lifecycle is intentionally gate-based. Agents can move quickly inside a phase, but transitions should be explicit.

## 1. Discovery

Output:

- Requirements
- Constraints
- Non-goals
- Unknowns

Gate: project owner approves requirements.

## 2. Planning

Output:

- Technical approach
- Milestones
- Risks
- Ownership map

Gate: project owner approves plan.

## 3. Design

Output:

- UX flow
- UI direction
- Content structure
- Accessibility notes

Gate: project owner approves design.

## 4. Build

Output:

- Working implementation
- Tests appropriate to risk
- Updated docs

Gate: technical lead confirms build is ready for QA.

## 5. QA

Output:

- Test results
- Known issues
- Release recommendation

Gate: project owner approves deployment or release.

## 6. Release

Output:

- Deployment notes
- Rollback plan
- Follow-up list

Gate: post-release check completed.
