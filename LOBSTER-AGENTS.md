# Lobster Agents LLC

## Company Structure

The roster is organized across product, engineering, quality, creative, business development, operations, and executive functions.

## File Organization

The installer writes private runtime state outside this repository:

- Project docs, assets, downloads: ~/Data/[project]
- Source repositories: ~/Source/[project]
- Company resources: ~/Data/lobsteragents

Keep credentials, browser profiles, local memory, and customer data outside git.
